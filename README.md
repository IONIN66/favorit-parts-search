# Поиск автозапчастей

Клиент на React, Redux Toolkit и Bootstrap. Код организован по Feature-Sliced Design: `app`, `pages`, `widgets`, `features`, `entities`, `shared`.

## Запуск

Нужен Node.js 22 (версия указана в `.nvmrc`), pnpm 10 и ключ покупателя Favorit Parts.

```bash
nvm use
pnpm install
cp .env.example .env
```

Укажите настоящий `FAVORIT_API_KEY` в `.env`, затем запустите два процесса. API-сервер сам читает `.env` при запуске:

```bash
pnpm api
```

В другом терминале:

```bash
pnpm dev
```

Страница откроется по адресу Vite, обычно `http://localhost:5173`.

Без действующего ключа запросы к Favorit Parts не выполняются. После его получения можно проверить пример артикула `7160500039S` из документации API.

Для сборки клиента используйте `pnpm build`. При размещении собранного сайта запросы `/api/parts` нужно направить на этот прокси или аналогичный серверный маршрут.

`pnpm lint` проверяет JavaScript/JSX через ESLint, архитектуру FSD через Steiger и форматирование через Prettier. Для форматирования файлов используйте `pnpm format`.

Браузер обращается к `/api/parts`. В режиме разработки Vite перенаправляет запрос на локальный прокси из `server/index.js`. Прокси добавляет ключ и отправляет запрос в HTTP API из спецификации. Ключ остаётся на сервере и не попадает в клиентский код.

Поиск производителей выполняется через 450 мс после ввода. При выборе бренда запрашиваются аналоги. Одна строка таблицы соответствует предложению конкретного склада; цену и остаток берём из `warehouses`, поскольку `goods.price` помечен в документации как устаревший.

Переключатель темы поддерживает светлый, тёмный и системный режимы. Выбор сохраняется в браузере; системный режим следует настройке ОС.
